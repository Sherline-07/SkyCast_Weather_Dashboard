# SkyCast — Real-Time Weather Dashboard

A responsive weather dashboard built with HTML, CSS, and vanilla JavaScript.

## Run the project
1. Open the folder in VS Code.
2. Start `index.html` using VS Code Live Server (recommended), or open it in a modern browser.
3. Search for a city such as Chennai, London, or Tokyo.

## Features
- City search
- Current temperature, humidity, wind speed, feels-like temperature, and condition
- Fetch API and async/await
- JSON response parsing
- Loading state and error handling
- Responsive layout

## APIs used
- Open-Meteo Geocoding API: converts a city name to coordinates.
- Open-Meteo Forecast API: returns current weather conditions for those coordinates.

Open-Meteo offers access without an API key for this type of use. See the official documentation at https://open-meteo.com/en/docs and https://open-meteo.com/en/docs/geocoding-api.

## JavaScript concepts demonstrated
`fetch()`, `async/await`, `try/catch/finally`, HTTP response checks, JSON parsing, DOM updates, and error handling.
